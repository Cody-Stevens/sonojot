# Security reports

Report suspected vulnerabilities privately to **support@sonojot.com**. Include the affected version, operating system, impact, and a minimal reproduction using synthetic data. Do not post vulnerabilities, credentials, recordings, or private transcripts in public issues. Arrange a safe transfer with the maintainer if sensitive material is necessary.

Security fixes target the latest release and the current main branch. Older releases may require an upgrade. This project has no bug bounty program and makes no response-time guarantee.
